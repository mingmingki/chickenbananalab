# ChickenBananaLab AI 연구소 — 초기 베타 (2026-11-06)

- 사이트: https://www.chickenbananalab.com/ai-lab/
- 접근: 기존 Django 계정 중 `is_staff=True`인 관리자만 가능.
- 구현: 대화 목록 생성·조회, 사용자별 자료 보관, 독립 모델 서버 연결용 채팅 API 및 상태 표시.
- 모델이 없으면 실제 대답을 생성하지 않으며 UI/채팅 API에서 준비 중을 명시.
- 자동매매 주문 기능, OKX 계정, 기존 거래 시스템의 AI API 키, 설정을 import하거나 읽지 않음.
- 학습/문서 자동 분석/BIM 분석은 **미구현**. 자료는 아직 보관만 가능.
- 별도 개인 데이터: `CBL_AI_DATA_DIR` (기본 `BASE_DIR.parent / cbl_ai_lab_private`).
- 저장: private SQLite 및 랜덤 토큰 파일명. 정적 폴더 및 공개 /media/ 경로가 아님.
- 업로드 파일: TXT, MD, CSV, JSON, PDF, IFC · 8MB 이하 · 서버가 내용 자동 실행하지 않음.

## 별도 GPU 모델 연결 (향후)

다른 서버에 OpenAI 호환 Chat Completions HTTPS 엔드포인트를 구성하고,
**치킨바나나랩 Django 서버에서만** 환경 변수 지정:

- `CBL_AI_MODEL`: 모델 ID
- `CBL_AI_API_BASE_URL`: 예: `https://ai-inference.example.com/v1`
- `CBL_AI_API_KEY`: 해당 모델 서버의 인증 키
- `CBL_AI_DATA_DIR`: 원하는 전용 데이터 디렉터리 (선택)

실제 도입 전 TLS, 방화벽/IP 접근제한, 호출량 제한, 비용 제한, 로깅 정책 및
개인정보 처리 방침을 별도 검토해야 한다. 기존 거래 서버와 연계하지 않는다.
