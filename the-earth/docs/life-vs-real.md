# 앤의 삶 vs 우리가 사는 세계

앤들의 하루와 평생을 실제 사람의 삶과 하나하나 견주어, 무엇이 있고 무엇이 빠졌는지 적어 두는 문서입니다.
새 기능을 넣을 때마다 이 표를 고칩니다. (● 있음 · ◐ 일부 · ○ 없음)

## 1. 먹는 것 — 이번에 크게 넓힌 부분

| 실제 삶 | 게임 | 상태 |
|---|---|---|
| 음식이 수천 가지 | 음식 사전 2,294가지 (`server/sim/foods.js`): 한식·일식·중식·동남아·인도·중동·아프리카·스페인/중남미·포르투갈/브라질·영미·독일·프랑스·이탈리아·러시아·원시 음식·세계 공통 음식 | ● |
| 시대마다 먹는 게 다르다 | 음식마다 처음 먹게 되는 시대. 불을 쓰기 전엔 날것만, 고추·감자는 중세 이후, 라면·짜장면은 산업 시대, 마라탕·탕후루는 정보화 시대, 배양육은 우주 시대 | ● |
| 고장마다 먹는 게 다르다 | 마을 먹을거리가 곡물·채소·과일·고기·생선·유제품으로 나뉨. 바닷가는 생선, 목장 마을은 고기. 시장이 생기거나 근대 이후엔 무엇이든 구함 | ● |
| 사람마다 입맛이 다르다 | 매운맛·단맛 선호, 새 음식을 반기는 정도, 유난히 싫은 맛, 좋아하는·싫어하는 음식 (먹어 보며 바뀜) | ● |
| 같은 것만 먹으면 물린다 | 최근 먹은 음식은 맛 점수가 깎임 | ● |
| 날씨에 따라 당기는 음식 | 추우면 국물, 더우면 냉면·빙수·콩국수 | ● |
| 엄마가 해 주던 맛 | 어릴 때 식구가 해 준 음식이 평생 '그리운 맛'이 됨 | ● |
| 식구가 함께 먹는 밥 | 집에서는 솜씨 좋은 식구가 차리고 다 같이 먹음 → 교류·정 | ● |
| 요리 솜씨 | '요리' 기술. 차릴수록 늘고, 요리사·셰프는 일하며 늘어남. 솜씨가 낮으면 어려운 음식은 못 함 | ● |
| 점심은 식당·구내식당·도시락 | 일하는 날 점심: 식당(대개) · 큰 회사 구내식당 · 도시락 · 옛날엔 새참 | ● |
| 식당마다 다르다 | 식당마다 요리 종류·메뉴·주방 솜씨·소문. 맛있는 집은 맛집으로 소문남, 솜씨 없는 집은 가끔 배탈 | ● |
| 외국 음식 | 근대 이후 다른 나라 음식점이 생김. "처음으로 ○○ 요리를 먹어 봤다" 기억 | ● |
| 배달 음식 | 근대 이후. 피곤하거나 주말이거나 요리할 사람이 없을 때 | ● |
| 회식 | 산업 시대 이후, 직원 넷 이상인 회사가 한 달에 한두 번. 회사가 내고, 술이 돌고, 동료와 친해짐 | ● |
| 명절·생일 음식 | 생일 미역국·케이크, 설날 떡국, 추석 송편, 동지 팥죽, 복날 삼계탕, 춘절 만두, 크리스마스 저녁 | ● |
| 커피·차 | 습관. 마시면 몇 시간 덜 피곤하고 능률이 오름. 늦게 마시면 잠이 얕음. 집에선 커피믹스, 밖에선 카페 음료 | ● |
| 술 | 습관·스트레스·함께 먹는 사람·주말에 따라. 스트레스가 풀리지만 과음하면 다음 날 숙취(능률 −20%) | ● |
| 밥을 먹어야 힘이 난다 | **컨디션** = 배부름·기력·기분·스트레스·건강·카페인·숙취·식단 → 일·공부·연구·집짓기·채집의 능률 (45~125%) | ● |
| 잘 먹으면 건강하다 | 식단 균형·군것질·체중·운동·술이 건강의 목표치를 바꿈 (오래 쌓여서 나타남) | ● |
| 살이 찌고 빠진다 | BMI: 문화권 평균 + 타고난 체형, 군것질·간식·술·중년은 찌우고 운동은 뺌, 굶으면 빠짐 | ● |
| 다이어트 | 살찐 성실한 사람이 결심, 마음 약한 사람은 무너짐 | ● |
| 장보기 | 생활비 속 '식비'로만 나감. 실제로 시장·마트에 가서 재료를 사 오지는 않음 | ◐ |
| 요리하는 시간 | 요리하는 사람이 따로 시간을 쓰지는 않음 (밥상은 바로 차려짐) | ○ |
| 음식 알레르기·채식 | — | ○ |
| 제철 재료·풍흉에 따른 값 | 풍년·가뭄은 양만 바뀜. 음식값은 시대별 고정 | ◐ |
| 편의점 | 편의점 음식(삼각김밥·도시락·컵라면)은 사전에 있지만 편의점이라는 가게는 아직 없음 | ◐ |

## 2. 몸과 건강

| 실제 삶 | 게임 | 상태 |
|---|---|---|
| 나이 들수록 약해진다 | 건강 목표치가 45세부터 내려가고 75세부터 더 빨리 | ● |
| 생활 습관이 건강을 만든다 | 식단·체중·운동·술·스트레스 | ● |
| 잠깐 앓는 병 | 감기·독감·장염·몸살·허리 통증·충치·폐렴 (+ 사건으로 열병·부상·과로·돌림병). 겨울 감기·독감, 여름 장염. 아이는 감기에 잘 걸림. 감기·독감은 식구에게 옮고, 앓고 나면 한동안 면역 (`server/sim/illness.js`) | ● |
| 오래 가는 병 | 고혈압·당뇨(체중·군것질·술·스트레스·짠 음식), 치매(일흔 무렵부터), 우울증(오래 지치고 외로울 때, 회복도 함), 암(나이·술). 건강 목표치를 깎음 | ● |
| 갑자기 쓰러지는 병 | 심근경색·뇌졸중 — 고혈압·당뇨·체중·술이 키우고 운동이 줄임. 병원이 있고 시대가 발전했을수록 살아남음. 살아나면 술을 줄이고 식단 조절 | ● |
| 병원·약 | 아프면 의원·병원에 가서 한 번 진찰 → 병 이름을 알고 빨리 나음, 심하면 종합병원 입원. 진찰 중에 숨어 있던 고혈압·당뇨가 발견됨 (혈압계가 없던 시대엔 못 찾음). 근대 이후 약으로 다스리고 약값이 가계부에 남음. 항생제 시대엔 폐렴이 빨리 나음. 암은 근대 이후 수술·항암으로 나을 수도 | ● |
| 다침·사고 | 화재로 다침, 사고사 | ◐ |
| 담배 | — | ○ |
| 치아·눈 (치과, 안경) | — | ○ |
| 마음의 병 (우울·불안·번아웃) | 우울증은 오래 가는 병으로, 번아웃은 사건(과로)으로 | ◐ |
| 잠의 질 | 집이 없거나 늦게 커피를 마시면 잠이 얕음 | ◐ |
