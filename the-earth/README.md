# The Earth 🌍

지구를 고르고, 나라를 고르고, **앤(Ann)** 들을 투입하세요.
그 다음부터 앤들은 스스로 생각하고, 사람을 만나고, 사랑하고, 일하고, 집을 짓고, 회사를 세우고, 나이 들어 갑니다.
**한 번 투입된 앤은 조종할 수 없습니다.** 지켜볼 수 있고, 앤이 인생의 갈림길에서 물어 오면 **마음속 목소리**로 조언할 수 있을 뿐입니다 ([앤이 묻는다](#앤이-묻는다)).

## 실행

```bash
cd the-earth
npm install
npm start            # http://localhost:3000
```

- 노드 22.13 이상 (내장 SQLite를 씁니다).
- 처음 실행하면 `제1서버`가 **1년 1월 1일 0시**에 열립니다. 월드·계정은 `data/worlds/earth.db` (SQLite) 에 1분마다 저장되고, 한 시간마다 백업(월드마다 최근 24개)이 남습니다. 예전 JSON 저장 파일이 있으면 처음 실행할 때 DB로 옮깁니다.
- **현실 1시간 = 게임 하루** (24배속). 현실 하루 = 게임 24일, 현실 15일 = 게임 1년. 아기로 태어난 앤은 현실 약 3개월 반 뒤에 초등학교에 들어가고, 9개월 반 뒤에 어른이 되며, 한평생은 현실 약 3년입니다.
- 개발할 때 빠르게 보고 싶으면 `npm run dev` (600배속, 누구나 서버 열기 가능. 배속은 저장되지 않음).
- 새 서버는 **관리자 페이지(`/admin`)** 에서 엽니다. 언제 열든 그 서버는 1년 1월 1일부터 시작합니다.
- 환경 변수는 아래 [운영](#운영) 표를 보세요.

## 휴대폰으로 하기 (아이폰·안드로이드)

- 컴퓨터에서 `npm start` 로 서버를 켜고, 같은 와이파이의 휴대폰 브라우저(Safari·Chrome)에서 `http://컴퓨터IP:3000` 을 엽니다. (맥: 시스템 설정 → Wi-Fi → 세부사항의 IP 주소, 윈도우: `ipconfig` 의 IPv4 주소)
- Safari 공유 버튼 → **홈 화면에 추가** 하면 아이콘이 생기고, 주소창 없이 앱처럼 전체 화면으로 열립니다.
- 조작: 한 손가락으로 끌면 이동, 두 손가락으로 벌리고 오므리면 확대·축소, 두 손가락을 비틀면 회전, 두 손가락을 함께 위아래로 밀면 기울이기, 두 번 톡톡 치면 그곳으로 확대.
- 화면: 앤 목록과 앤 정보는 아래에서 올라오는 시트입니다 (손잡이를 눌러 접고 펴기). 위쪽 절반은 늘 세상이 보이도록 카메라가 올라갑니다. 가로로 눕히면 목록은 왼쪽, 앤 정보는 오른쪽에 세로로 나옵니다. 노치·홈 막대를 피해 배치됩니다.
- 성능: 휴대폰에서는 화면 해상도 1.5배, 초당 30장, 지구·지면 텍스처와 나무·비·눈 입자 수, 이름표 수를 줄여 발열과 배터리를 아낍니다. 잠금 화면에서 돌아오면 서버 연결을 바로 다시 잇습니다.

## 지구

- **실제 지구 사진**: NASA 블루 마블 위성 사진(퍼블릭 도메인)으로 그린다. 컴퓨터는 4K, 휴대폰은 2K. 사진을 못 받으면 예전처럼 국경 다각형으로 그린 지도로 대신한다.
- **계절**: 겨울(1월)에는 북반구가 눈으로 하얗고, 여름(7월)에는 초록으로 바뀐다 — 게임 속 날짜를 따른다.
- **지형 음영**: 실제 높이 지도로 산맥이 햇빛 방향에 따라 도드라진다 (히말라야·안데스·로키·알프스). 가까이 내려가면 사진이 뭉개지지 않게 잔무늬가 더해진다.
- **구름**: 실제 구름 사진이 게임 속 20일에 한 바퀴씩 흘러가고, 땅에 구름 그림자가 진다.
- **바다**: 수심에 따라 색이 다르고(대륙붕은 밝게), 햇빛이 반사되어 반짝인다.
- **밤**: 불빛은 실제 도시가 아니라 **앤들이 세운 마을**에서만 켜진다 (원시 시대의 지구는 깜깜하다).
- **지명**: 높이 있을 때는 대양·대륙, 내려가면 바다·산맥·사막 이름이 보인다. 국경선은 나라를 고를 때 또렷하고, 마을 가까이 내려가면 사라진다.
- **움직이기**: 마우스 휠·두 손가락으로 **가리킨 곳을 향해** 확대·축소된다 (구글 어스처럼). 끌어서 이동(관성), 오른쪽 버튼·Shift+끌기로 돌리기·기울이기, 두 번 눌러 그곳으로 확대. 키보드: 방향키 이동, +/- 확대·축소, Q/E 돌리기, PageUp/PageDown 기울이기.

사진 출처: NASA Visible Earth — Blue Marble (퍼블릭 도메인), npm 패키지 three-globe·earth-visualization(MIT)에 들어 있는 사본을 가공해 `public/textures/earth/` 에 넣었다.

## 계정·알림·소리

- **로그인은 선택**입니다. 로그인하지 않으면 게임은 그 기기(브라우저)에만 저장되고, 로그인하면 어느 기기에서든 이어할 수 있습니다. 로그인하는 순간 그 기기에서 하던 게임이 계정에 붙습니다.
- **구글 로그인**: 'Google로 계속하기' 한 번이면 됩니다 (처음이면 게임 아이디만 정함). 구글에서는 계정 고유번호만 받고 이메일·이름은 받지 않습니다. 아이디·비밀번호 계정에 나중에 구글을 연결할 수도 있습니다. 아이폰 '홈 화면 앱'에서 누르면 Safari에서 로그인이 열리는데, 로그인 후 Safari에 나오는 **6자리 확인 코드**를 앱에 입력하면 됩니다 (홈 화면 앱과 Safari는 저장소가 따로라서). 같은 브라우저로 돌아오면 코드 없이 바로 이어집니다.
- **처음 안내**: 처음 앤을 투입하면 화면 곳곳을 짚어 주는 안내가 나옵니다 (⚙️ 설정 → 처음 안내 다시 보기).
- **그동안 있었던 일**: 이어하기로 돌아오면 자리를 비운 동안 내 앤들에게 있었던 일(탄생·결혼·죽음·취업·창업…)과 나라의 역사를 한 장으로 보여 줍니다.
- **🔔 알림함·🏆 업적**: 내 앤의 큰 소식이 쌓이고, 첫 출근·결혼·다음 세대·대학 졸업·창업·나라의 지도자·우주 비행·시대 개막 같은 업적 30여 가지를 모읍니다.
- **휴대폰 알림**: 로그인 후 ⚙️ 설정 → 휴대폰 알림 켜기. 앱을 닫아 둬도 큰 소식을 모아서(중요한 건 2분, 나머지는 20분 간격) 보냅니다. 아이폰은 Safari **공유 → 홈 화면에 추가** 로 설치한 앱에서만 켤 수 있습니다 (iOS 16.4 이상). 화면을 보고 있을 때는 푸시 대신 화면 안 알림만 띄웁니다.
- **소리**: 파일 없이 브라우저에서 만들어 냅니다. 바람(높이·날씨), 비와 천둥, 낮의 새소리, 여름·가을 밤의 풀벌레, 마을 소음과 자동차(산업 시대 이후), 우주의 낮은 울림, 시간·시대에 따라 바뀌는 잔잔한 음악, 탄생·결혼·죽음·업적 효과음. 설정에서 전체·음악·환경음·효과음을 따로 조절합니다.
- **신고**: 다른 사람의 앤 정보 창의 🚩 로 부적절한 앤·플레이어 이름을 신고하면 관리자 페이지에 쌓입니다. 욕설·혐오 표현·운영자 사칭 이름은 처음부터 막습니다 (띄어쓰기·숫자 섞기도 잡아냄).

## 게임 흐름

1. **인트로** — 위에서 지구가 떨어져 내려앉고, `시작하기` / `이어하기`.
2. **서버 선택** — 각 서버의 현재 날짜·인구·플레이어 수. 관전만 할 수도 있습니다.
3. **나라 선택** — 3D 지구를 돌려 실제 국경의 나라를 고릅니다 (Natural Earth 1:50m, 240개 지역). 같은 나라를 고른 다른 플레이어의 앤들과 한 마을에서 살게 됩니다.
4. **앤 만들기** — 이름, 성별, 나이, 성격 5요소(개방성·성실성·외향성·친화성·신경성), 능력(지능·운동신경·창의성·매력·건강, 총 300점), 야망. 플레이어당 최대 12명.
5. **관찰** — 우주 전체(360° 별하늘, 은하수, 태양, 달, 행성)에서 마을 골목길까지 끊김 없이 확대됩니다.
   - 드래그: 이동 · 휠/핀치: 확대 · 오른쪽 드래그(또는 Shift+드래그, 두 손가락): 회전·기울이기 · 더블클릭: 그곳으로 확대
   - 앤을 클릭하면 **속마음, 고민 과정(왜 그 행동을 골랐는지), 성격·능력·기술, 관계, 기억, 인생, 꿈** 을 볼 수 있습니다.
   - 다른 플레이어의 앤도 모두 관찰할 수 있습니다.

## 앤이 투입되면

- **가정이 있는 나라**: 앤은 무작위로 고른 가정(부부·연인)에서 **아기로 태어납니다.** 먼저 들어온 다른 플레이어의 앤들이 부모가 될 수도 있습니다. 성은 집안을 따르고, 플레이어가 정한 성격·능력·야망은 타고난 기질이 됩니다. 외모는 부모를 닮습니다. (부부가 아이를 낳을 수 없는 경우엔 입양)
- **가정이 하나도 없는 나라**: 앤은 **개척자(어른)** 로 도착합니다.
- 오른쪽 **연대기**에는 "○○마을, 김민준과 이서연의 초가집에서 태어났다 → 첫 말 '엄마' → 첫걸음 → 첫 친구 → ○○서당 입학 → 시험 1등 → 첫사랑 → 졸업 → 첫 월급…" 같은 인생이 나이별로 쌓입니다.

## 처음은 어떻게 시작되나 (자연뿐인 땅에서)

1. 땅에는 **산, 언덕, 강, 바다, 호수, 숲**뿐입니다 (해안선은 실제 지도에서, 산맥은 실제 산맥 위치에서, 마을 주변 지형은 절차적으로 생성). 건물은 하나도 없습니다.
2. 개척자들은 먼저 **먹을 것**을 찾습니다 — 숲에서 채집하고, 사냥하고, 물가가 있으면 고기를 잡습니다 (물가가 없으면 어부도 없음).
3. 누군가 **모닥불**을 피우고(나라 최초 기록), 각자 손수 **움집**을 짓습니다.
4. 사람들이 사귀고, 족장이 추대되고, 연구로 기술이 쌓여 **농경 시대**가 열립니다. 이때는 흙벽돌을 손수 찍어 쌓은 **초가집**을 짓고, 친한 이웃들이 **품앗이**로 거듭니다 (연대기에 "이웃 3명의 품앗이"가 남음).
5. 고대의 **기와집·벽돌집**에는 구운 벽돌·기와가 필요합니다 → 누군가 **벽돌 가마**를 차려야 합니다. 벽돌이 없으면 공사가 멈추고, 그게 곧 벽돌 사업의 기회가 됩니다. 시장·관청·학교 같은 **큰 건물**, 중세의 **벽돌집**, 산업 시대 이후의 **연립·아파트**는 **건설회사**가 있어야 제대로 지어집니다 (기와집까지는 이웃끼리 품앗이로 손수 짓습니다).
6. 부부가 생기고 아이들이 태어납니다. 아이들은 **나이에 맞는 학교가 마을에 있어야** 다닙니다: 서당(고대) → 유치원·초등학교·중학교·고등학교·대학교. 학교가 없으면 연대기에 "학교가 없어 다니지 못했다"가 남고, 지도자는 아이 수를 보고 학교를 세웁니다.
7. 학력이 있어야 될 수 있는 직업이 있습니다 (의사·과학자·엔지니어·교수 = 대학교, 교사 = 고등학교…). 대학이 막 생긴 시대에는 졸업생이 없으니 나라에서 가장 많이 배운 사람이 가르칩니다 — 세대가 바뀌며 전문직이 생겨납니다.
8. 나라마다 **"최초" 연대기** 가 남습니다: 첫 불, 첫 움집, 첫 고기잡이, 첫 족장, 첫 연인, 첫 결혼식, 첫 아기, 첫 회사, 첫 건설회사, 첫 서당, 첫 학생, 첫 졸업생, 첫 홍수…

## 시대의 흐름 (현실 1시간 = 게임 하루 기준, 대략)

원시에서 중세까지는 '프롤로그'처럼 빠르게, 학교·회사·아파트가 있는 근대 이후를 길게 지켜보도록 맞췄습니다.

| 시대 | 게임 시간 | 현실 시간 |
|---|---|---|
| 농경 | 몇 달 | 며칠 |
| 고대 | 1년 남짓 | 2~3주 |
| 중세 | 3~4년 | 약 2개월 |
| 산업 | 8년 안팎 | 약 4개월 |
| 근대 | 16년 안팎 | 약 8개월 |
| 정보화·우주 | 30~45년 | 1~2년 |

인구와 학교가 늘수록 기술이 빨라지므로, 실제 속도는 나라마다 다릅니다.

## 일과 하루 (현실처럼)

- **근무 시간표**: 직업마다 다르다 — 현장 07~17시(주 6일), 사무실 09~18시(주 5일), 공장 08~17시, 식당 10~21시, 학교 08~16:30, 농부는 새벽부터 해 질 녘까지(겨울엔 짧게), 어부는 새벽 출항. 성실하지 않으면 지각한다. 산업 시대 전엔 주 6일.
- **하루**: 일어나기 → 아침 → 출근(집에서 일터까지 걸어간다) → 12시 점심(식당이 있으면 식당, 매출이 식당으로) → 오후 근무 → 퇴근 → 저녁·가족·친구 → 잠. 앤 화면의 연대기 탭에 **"오늘 하루"** 가 현지 시각으로 남는다.
- **건설 현장**: 건물마다 실제에 가까운 공사량(사람×시간)이 있다. 아파트 24,000 → 10명이 약 1년, 학교 7,000, 제철소 60,000. 건설회사가 공사를 맡으면 직원을 **현장에 배치**하고, 그 앤은 준공까지 매일 그 현장으로 출근한다 (연대기: "현장 배치 → 14개월 만에 준공"). 일감이 밀리면 사람을 더 뽑고, 현장이 없어도 기본 인력은 유지한다. 기존 건설회사들이 감당 못할 만큼 일감이 넘칠 때만 새 건설회사가 생긴다.
- **창업**: 사옥·가마를 짓는 동안 대표는 월급 없이 일한다. 적자가 이어지면 먼저 채용을 멈추고, 그래도 안 되면 한 명씩 줄인다. 망해 본 업종은 2년 동안 다시 하지 않는다. 가게·회사는 어른 다섯 명에 하나꼴까지 생기고, 나머지는 거기에 취직한다.
- **임금**: 일손이 모자란 회사는 (낼 형편이 되면) 임금을 조금씩 올린다 — 최대 60%. 그래서 자영농이 벽돌 가마나 식당으로 옮겨 간다. 사람이 차면 시세로 돌아간다.
- **조직 규모**: 건물마다 정원이 있다 (미용실 6, 식당 15, 시청 40, 공장 150, 종합병원 300, 제철소 600, 조선소 800). 장사가 잘되면 정원까지 사람을 늘리고, 꽉 차면 건물을 하나 더 짓는다.
- **산업과 지형**: 바다가 있어야 조선소·수산, 물가가 있어야 선착장, 산이 있어야 광산, 숲이 있어야 목재소. 광산이 있어야 제철, 제철이 있어야 조선·중공업·자동차, 화학이 있어야 전자, 전자가 있어야 우주항공. 철이 모자라면 공장이 제대로 돌아가지 않는다.
- **집**: 산업 시대부터는 건설회사(또는 정부)가 연립·아파트를 지어 분양·임대하고, 입주한 앤은 월세를 낸다.
- **공공**: 관청(→시청), 학당, 신전, 학교들, 경찰서, 소방서, 우체국, 종합병원, 기차역, 발전소, 국립 연구소 — 인구가 늘면 지도자가 성격대로 순서를 정해 세운다. 단, **관청과 학교가 먼저**: 그 돈이 모자란 동안 다른 기관은 미루고 공무원 채용도 동결한다. 오래 모자라면 지도자가 세금을 올리고("초등학교를 세우려면 돈이 필요합니다"), 곳간이 넘치면 내린다.
- **나라 살림**: 월급·배당·자영업 소득에서 세금을 걷는다. 공무원 인건비는 세수의 65%까지. 빈 자리가 오래가면 관청이 마을의 알맞은 사람(무직·자영업)을 **임용**한다 (연대기: "초등학교 교사 임용").

- **연봉**: 2026년 한국 공개 자료를 참고한 직업별 세전 중간값 (최저임금 시급 10,320원 = 월 2,156,880원, 근로자 중위 연봉 약 3,417만원, 의사 평균 보수 약 2.85억원, 소프트웨어 개발 평균 5,526만원 등). '정보화 시대'에 이 금액이고, 이전 시대엔 시대의 임금 수준만큼 낮다 (현재 가치로 환산). 실제 월급은 숙련(±15%)·직급(단계마다 +10%)·구인난 웃돈(최대 30%)에 따라 달라지고, 근대부터는 최저임금보다 적게 줄 수 없다.
- **시대마다 다른 돈**: 원시 조개 → 농경 곡식(1섬 = 100되) → 고대 전(1관 = 1,000전) → 중세 냥(1냥 = 10전 = 100푼, 쌀 한 섬 5냥 남짓) → 산업 원(1960~70년대 물가: 짜장면 100원, 공장 월급 2만원) → 근대 원(1990년대: 직장인 월급 100만원 남짓) → 정보화 원(2026년) → 우주 원(2060년대 예상). 옛 시대 금액 옆에는 '오늘 돈으로 약 얼마'를 함께 보여 준다.
- **시대마다 다른 월급 구조**: 원시·농경엔 다들 비슷하게 벌고, 고대·중세엔 관리·학자·사제·상인·대장장이가 대우받고, 산업 시대엔 광부·선원(위험수당)·은행원, 근대(1990년대)엔 변호사·은행원, 우주 시대엔 AI·우주 엔지니어가 오르고 계산원·상담원·운전기사는 자동화로 줄어든다.
- **시대마다 다른 생활비**: 농경 곡식·짚신 → 고대 땔감·약값 → 중세 쌀·땔나무·서당 훈장님 사례 → 산업 쌀·부식·연탄·버스비·셋방 월세·과외 → 근대 집전화·삐삐·버스·지하철·자가용·학원비 → 정보화 통신비·자동차·학원비 → 우주 통신·클라우드·자율주행 구독·AI 맞춤 학습. 최저임금(1988년~), 4대보험(1990년대 약 4.8% → 2026년 9.72% → 우주 12%), 국민연금도 시대에 따라 생긴다.

## 공사·도로·치안·소방·날씨 (눈으로 보이는 것들)

- **공사 과정이 보인다**: 펜스·터파기(산업 시대부터는 굴착기) → 기초 슬래브 → 골조(현대: 콘크리트 기둥과 층 슬래브, 옛날: 나무 기둥과 들보)가 층층이 올라가고 비계·안전망이 둘러진다 → 높은 건물엔 **타워크레인**(일하는 날엔 지브가 돈다) → 외벽이 아래부터 차오른다 → 지붕을 얹고 → 비계를 걷으면 완공. 벽돌이 모자라 멈춘 현장엔 공사 중단 표지가 선다.
- **건물 디테일**: 시대·용도별 외벽(흙벽, 초가, 한옥 창살, 벽돌, 콘크리트, 유리 커튼월, 공장 철판), 문과 현관 캐노피, 가게의 차양·간판, 아파트 발코니, 옥상 설비·난간·항공 장애등, 굴뚝 연기(공장은 늘, 집은 추울 때), 처마가 들린 기와지붕과 용마루, 소방서 차고와 소방차, 경찰서 순찰차, 병원 십자가, 학교 운동장. 밤에는 창마다 불이 켜진다.
- **도로는 등급이 있고, 기간이 걸려 좋아진다**: 흙길 → 자갈길(고대) → 돌길(중세) → 포장도로(산업, 인도·중앙선·가로등) → 대로(근대, 차선·횡단보도·가로수·신호등). 사람이 다니면 흙길이 생기지만, 그 다음부터는 **관청에 도시환경과**(대로는 **교통과**)가 생겨야 한다. 도시환경과가 예산을 잡아 "중앙로 아스팔트 포장" 같은 공사를 계획하면 건설회사(없으면 일용직·이웃)가 구간마다 몇 달씩 걸려 깐다. 공사 구간은 주황·흰 줄무늬와 고깔로 막히고, 새 노면이 앞에서부터 깔린다.
- **관청 부서**: 총무과 → 도시환경과(공무원 3명) → 복지과(산업 시대) → 교통과(근대). 부서가 생기면 공무원 한 명이 발령받고, 연대기에 남는다.
- **치안**: 산업 시대 전에는 관청의 **포졸**, 그 뒤로는 **경찰서**의 경찰관이 동네를 순찰한다(근무 중엔 모자를 쓴다). 도둑이 들면 쫓아가 붙잡고("포졸 ○○이 도둑을 붙잡았다 — 범인은 ○○"), 되찾은 재산을 돌려준다. 붙잡힌 앤은 평판을 잃고 한동안 다시는 손대지 않는다. 치안 인력이 많을수록 도둑이 줄어든다.
- **소방**: 불은 겨울과 가뭄에 잘 난다. 소방서가 있으면 근무 중인 소방관(빨간 헬멧)이 현장으로 달려가 금방 끄지만, 없으면 이웃들이 물을 길어 날라도 다 타 버리기 쉽다. 타 버린 집은 뼈대만 남아 다시 지어야 하고, 사는 사람들은 집을 잃는다. 불난 건물엔 불길과 검은 연기가 솟는다.
- **날씨와 계절**: 가까이 내려가면 비가 내리고(폭우·태풍엔 번개와 바람), 눈이 내리고, 안개가 낀다. 흐린 날엔 하늘이 잿빛으로 낮아지고 해가 약해진다. 눈은 추운 날 쌓이고(땅·지붕·밭·흙길이 하얗게, 포장도로는 제설되어 덜) 따뜻해지면 녹는다. 나무는 봄엔 연두와 벚꽃, 여름엔 짙은 초록, 가을엔 단풍, 겨울엔 앙상해지고 상록수만 푸르다. 밭도 계절 따라 색이 바뀐다.

## 교통: 자동차·버스·신호등 (인시 단위 공사)

- **자동차**: 근대(5시대)부터 형편이 되는 앤이 차를 산다. 출퇴근처럼 160m 넘게(다른 볼일은 230m) 가면 차를 몰고, **길 그물을 따라** 가장 빠른 길로 간다 (흙길 시속 12km → 대로 36km). 걷던 앤이 길을 가로지르지 않고 모퉁이를 돈다. 집 옆에는 세워 둔 차가 보인다 (아파트는 지하 주차장이라 몇 대만 밖에).
- **버스**: 버스 회사(없으면 관청의 **공영버스** — 인구 80명부터, 돈은 나라 곳간에서)가 생기면 마을 둘레를 도는 노선을 긋고 **정류장부터 짓는다**. 정류장이 다 지어져야 개통하고, 버스는 **기사가 출근해 있어야** 달린다. 기사는 오전조(05:30~14:00)·오후조(13:30~23:30)로 나뉘어 첫차부터 막차까지 이어 달리고, 운행 중에 기사가 없어지면 다음 정류장에서 손님을 모두 내려 주고 선다. 승객은 정류장까지 걸어가 기다렸다가(35분 넘게 안 오면 걸어감) 타고, 내려서 다시 걷는다. 걷는 게 더 빠르면 걷지만 비·눈·추위·더위, 65세 이상, 피곤할 때는 좀 느려도 버스를 탄다. 앤 정보에 "🚏 시장 앞 정류장에서 버스 기다리는 중" 처럼 나온다.
- **신호등**: 저절로 생기지 않는다. 관청에 **교통과**가 생기면(근대, 공무원 5명 이상) 교차로마다 하루 통행량을 세고, 하루 30대 넘게 지나는 교차로에 신호등을 계획한다. 다 지으면 90초 주기(남북 초록 40초·노랑 5초·동서 초록 40초·노랑 5초)로 돌고, 차와 버스는 빨간불에 정지선에서 선다. 한국식 가로형 3구 신호등, 네 방향 횡단보도와 정지선이 그려진다.
- **인시(사람×시간) 공사**: 신호등·정류장은 단계마다 정해진 인시를 일꾼들이 채워야 하고, 한 번에 붙을 수 있는 인원도 정해져 있다. 콘크리트 양생처럼 **사람이 많아도 줄일 수 없는 기다림**도 있다. 화면의 마을 정보에 단계·투입 인시·남은 양생 기간이 나온다.

- **나라 살림**: 소득세·4대보험·배당소득세에 더해 **부가가치세**(근대부터 물건값의 10/110)와 **법인세**(이익의 18~20%)가 들어온다. 회사원도 **공무원 시험**을 쳐서 관청·학교·경찰 등으로 옮겨 오므로, 마을이 커지면 공공기관도 제대로 사람을 채운다.

## 문명

- **시대**: 원시 → 농경 → 고대 → 중세 → 산업 → 근대 → 정보화 → 우주. 연구·학자·과학자가 쌓은 기술력으로 넘어가며, 시대마다 여섯 가지 발견(불, 바퀴, 문자, 인쇄술, 증기기관, 인터넷, 로켓…)을 누군가 해낸다.
- **경제**: 시대마다 직업이 바뀐다 (채집꾼·사냥꾼 → 농부·목수 → 상인·학자 → 의사·교사 → 공장 노동자·엔지니어 → 과학자·기자 → 프로그래머 → 우주비행사). 야망 있는 앤은 수요가 있는 산업에 회사를 세우고, 친분과 실력으로 직원을 뽑고, 경쟁에서 지면 파산한다.
- **정치**: 족장(추대) → 왕(세습) → 선거로 뽑는 대통령. 지도자의 성격에 따라 세율, 복지, 학당·학교·연구소를 짓는 순서가 달라진다.
- **도시**: 모닥불과 움집에서 시작해 초가집, 기와집, 벽돌집, 아파트, 초고층 빌딩으로. 건물 수와 시대에 따라 야영지 → 마을 → 읍 → 도시 → 대도시 → 메가시티. 붐비면 모험심 있는 앤이 새 땅을 개척하지만, 사람은 대개 모여 산다 — 새 정착지는 인구 40~50명에 하나꼴로만 생겨서, 큰 마을이 도시로 자란다.

`npm run simulate -- 730 3 KR` 로 화면 없이 2년을 빠르게 돌려 세계가 어떻게 흘러가는지 볼 수 있습니다.

## 운영

### 배포 (호스팅)

시뮬레이션이 서버 안에서 쉬지 않고 돌아가므로 **꺼지지 않는 서버 1대 + 영구 디스크**가 필요합니다 (서버리스·무료 슬립 플랜은 맞지 않음). 여러 대로 늘리면 세계가 갈라지므로 **반드시 1대**로 운영합니다.

**Fly.io** (도쿄 `nrt` 지역 — 한국에서 가까움)
```bash
cd the-earth
fly launch --no-deploy --copy-config      # fly.toml 의 app 이름을 바꾸라고 하면 바꾸기
fly volumes create earth_data --size 1 --region nrt
fly secrets set ADMIN_USERS=내아이디 OPERATOR_NAME="운영자 이름" OPERATOR_EMAIL=me@example.com VAPID_SUBJECT=mailto:me@example.com PUBLIC_URL=https://앱이름.fly.dev
fly secrets set GOOGLE_CLIENT_ID=... GOOGLE_CLIENT_SECRET=...   # 구글 로그인을 쓸 때
fly deploy
```

**Render**: 대시보드 → New → Blueprint → 이 저장소. 저장소 맨 위의 `render.yaml` 이 `the-earth/Dockerfile` 로 빌드하고 1GB 디스크를 `/data` 에 붙입니다. 디스크는 유료 플랜(Starter 이상)에서만 됩니다. 처음 만들 때 `ADMIN_USERS`, `OPERATOR_NAME`, `OPERATOR_EMAIL`, `VAPID_SUBJECT` 값을 물어봅니다.

**구글 로그인 켜기** (선택): [Google Cloud 콘솔](https://console.cloud.google.com/) → API 및 서비스 → OAuth 동의 화면(외부, 앱 이름·지원 이메일) → 사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → 유형 '웹 애플리케이션' → 승인된 리디렉션 URI에 `https://내주소/api/auth/google/callback` → 나온 클라이언트 ID·보안 비밀을 `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` 에, 사이트 주소를 `PUBLIC_URL` 에 넣습니다. 범위(scope)는 `openid` 하나만 씁니다. 동의 화면에 앱 이름·로고를 띄우려면 구글의 브랜드 확인을 받아야 합니다.

**그 밖의 곳** (VPS, Railway 등): `the-earth/Dockerfile` 로 이미지를 만들고 `/data` 에 영구 디스크를 연결, 포트 8080. 도커 없이 하려면 노드 22.13 이상에서 `npm ci --omit=dev && npm start`.

배포 뒤 할 일: ① `ADMIN_USERS` 에 적은 아이디로 가입 → 자동으로 관리자, ② `https://주소/admin` 에서 서버 상태 확인, ③ 휴대폰에서 주소를 열고 홈 화면에 추가 → 알림 시험.

### 환경 변수

| 이름 | 뜻 |
|---|---|
| `PORT` | 포트 (기본 3000, 도커는 8080) |
| `DATA_DIR` | DB 저장 위치 (도커는 `/data`) |
| `ADMIN_USERS` | 관리자 아이디 (쉼표로 여러 명). 비워 두면 **처음 가입한 계정**이 관리자 — 공개 배포 땐 꼭 지정하세요 |
| `ADMIN_KEY` | 계정 없이 관리자 페이지에 들어가는 비상 키 |
| `OPERATOR_NAME`, `OPERATOR_EMAIL`, `LEGAL_DATE`, `HOST_NAME`, `HOST_REGION` | 이용약관·개인정보 처리방침의 빈칸 (`/terms`, `/privacy`) |
| `VAPID_SUBJECT` | 푸시 알림 발신자 (`mailto:메일주소`). 키(`VAPID_PUBLIC_KEY`/`VAPID_PRIVATE_KEY`)는 비워 두면 처음에 만들어 DB에 저장 |
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` | 구글 로그인 (둘 다 있어야 버튼이 나타남) |
| `PUBLIC_URL` | 사이트 주소 (예: `https://the-earth.fly.dev`) — 구글 로그인 돌아올 주소에 씀 |
| `TRUST_PROXY` | 앞단 프록시 뒤라면 `1` (Fly·Render는 자동) — IP별 요청 제한에 씀 |
| `TIME_SCALE` | 개발용 배속 (예: 600) |
| `OPEN_SERVERS` | `1` 이면 누구나 새 서버를 열 수 있음 (개발용) |
| `RATE_LIMIT`, `WS_PER_IP` | 부하 시험용: `RATE_LIMIT=off`, `WS_PER_IP=10000` |

### 관리자 페이지 (`/admin`)

개요(가동 시간, 1초 처리 시간, 메모리, 접속자, 계정·신고 수), 서버(열기·일시정지·이름·즉시 저장·삭제), 플레이어(이름 바꾸기·내보내기 — 앤들은 주인 없이 계속 삶, 앤 이름 바꾸기), 신고 처리, 계정(이용 정지·관리자 지정), 백업 되돌리기, 최근 오류.

### 보안

비밀번호는 scrypt로 한 방향 암호화, 로그인 토큰은 무작위 256비트(60일). IP별 요청 제한(통신사 공유 IP를 생각해 넉넉하게: 가입 시간당 30회, 로그인 10분 60회, 게임 시작 시간당 40회, 투입 10분 60회, API 분당 600회), 비밀번호는 아이디별로 10번 틀리면 15분 잠금, 웹소켓 IP당 12개·메시지 크기 4KB·10초 60개 제한, 보안 헤더(CSP·X-Frame-Options 등), 느린 연결은 건너뛰어 메모리 보호. `/healthz` 로 상태 확인.

### 부하 시험

```bash
RATE_LIMIT=off WS_PER_IP=10000 npm start
npm run loadtest -- --server s1 --clients 200 --players 30 --seconds 60
```

### 법적 고지

`/terms`(이용약관)와 `/privacy`(개인정보 처리방침)는 한국 법(개인정보 보호법) 기준의 **초안**입니다. 운영자 정보를 환경 변수로 채우고, 공개 전에 한 번 검토하세요. 회원 탈퇴는 설정 화면에서 바로 할 수 있고, 계정·로그인 기록·알림 구독이 즉시 지워집니다.
