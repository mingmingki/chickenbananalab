# The Earth 🌍

지구를 고르고, 나라를 고르고, **앤(Ann)** 들을 투입하세요.
그 다음부터 앤들은 스스로 생각하고, 사람을 만나고, 사랑하고, 일하고, 집을 짓고, 회사를 세우고, 나이 들어 갑니다.
**한 번 투입된 앤은 조종할 수 없습니다.** 지켜보는 것만 가능합니다.

## 실행

```bash
cd the-earth
npm install
npm start            # http://localhost:3000
```

- 노드 20 이상.
- 처음 실행하면 `제1서버`가 **1년 1월 1일 0시**에 열립니다. 월드는 `data/worlds/<서버id>.json` 에 1분마다 저장됩니다.
- 시간은 현실의 **10배** 로 흐릅니다 (현실 2시간 24분 = 게임 하루, 현실 36.5일 = 게임 1년).
- 개발할 때 빠르게 보고 싶으면 `TIME_SCALE=600 npm start` (저장되지 않는 실행 중 배속).
- 새 서버는 화면의 **＋ 새 서버 열기** 로 언제든 열 수 있고, 언제 열든 그 서버는 1년 1월 1일부터 시작합니다. 관리자만 열게 하려면 `ADMIN_KEY=비밀 npm start`.
- `PORT`, `DATA_DIR` 환경 변수로 포트와 저장 위치를 바꿀 수 있습니다.

## 게임 흐름

1. **인트로** — 위에서 지구가 떨어져 내려앉고, `시작하기` / `이어하기`.
2. **서버 선택** — 각 서버의 현재 날짜·인구·플레이어 수. 관전만 할 수도 있습니다.
3. **나라 선택** — 3D 지구를 돌려 실제 국경의 나라를 고릅니다 (Natural Earth 1:50m, 240개 지역). 같은 나라를 고른 다른 플레이어의 앤들과 한 마을에서 살게 됩니다.
4. **앤 만들기** — 이름, 성별, 나이, 성격 5요소(개방성·성실성·외향성·친화성·신경성), 능력(지능·운동신경·창의성·매력·건강, 총 300점), 야망. 플레이어당 최대 12명.
5. **관찰** — 우주 전체(360° 별하늘, 은하수, 태양, 달, 행성)에서 마을 골목길까지 끊김 없이 확대됩니다.
   - 드래그: 이동 · 휠/핀치: 확대 · 오른쪽 드래그(또는 Shift+드래그, 두 손가락): 회전·기울이기 · 더블클릭: 그곳으로 확대
   - 앤을 클릭하면 **속마음, 고민 과정(왜 그 행동을 골랐는지), 성격·능력·기술, 관계, 기억, 인생, 꿈** 을 볼 수 있습니다.
   - 다른 플레이어의 앤도 모두 관찰할 수 있습니다.

## 앤이 투입되면

- **가정이 있는 나라**: 앤은 무작위로 고른 가정(부부·연인)에서 **아기로 태어납니다.** 먼저 들어온 다른 플레이어의 앤들이 부모가 될 수도 있습니다. 성은 집안을 따르고, 플레이어가 정한 성격·능력·야망은 타고난 기질이 됩니다. 외모는 부모를 닮습니다. (부부가 아이를 낳을 수 없는 경우엔 입양)
- **가정이 하나도 없는 나라**: 앤은 **개척자(어른)** 로 도착합니다.
- 오른쪽 **연대기**에는 "○○마을, 김민준과 이서연의 초가집에서 태어났다 → 첫 말 '엄마' → 첫걸음 → 첫 친구 → ○○서당 입학 → 시험 1등 → 첫사랑 → 졸업 → 첫 월급…" 같은 인생이 나이별로 쌓입니다.

## 처음은 어떻게 시작되나 (자연뿐인 땅에서)

1. 땅에는 **산, 언덕, 강, 바다, 호수, 숲**뿐입니다 (해안선은 실제 지도에서, 산맥은 실제 산맥 위치에서, 마을 주변 지형은 절차적으로 생성). 건물은 하나도 없습니다.
2. 개척자들은 먼저 **먹을 것**을 찾습니다 — 숲에서 채집하고, 사냥하고, 물가가 있으면 고기를 잡습니다 (물가가 없으면 어부도 없음).
3. 누군가 **모닥불**을 피우고(나라 최초 기록), 각자 손수 **움집**을 짓습니다. 움집까지는 혼자서도 지을 수 있습니다.
4. 사람들이 사귀고, 족장이 추대되고, 연구로 기술이 쌓여 **농경 시대**가 열립니다.
5. 그때부터 제대로 된 집(초가집 이상)과 가게·공방은 **건설회사(목수)가 있어야** 지을 수 있습니다. 집을 원하는 사람이 많은데 목수가 없으면, 그게 곧 야망 있는 앤에게 사업 기회가 됩니다 → **첫 건설회사** → 그 다음에야 다른 회사들.
6. 부부가 생기고 아이들이 태어납니다. 아이들은 **나이에 맞는 학교가 마을에 있어야** 다닙니다: 서당(고대) → 유치원·초등학교·중학교·고등학교·대학교. 학교가 없으면 연대기에 "학교가 없어 다니지 못했다"가 남고, 지도자는 아이 수를 보고 학교를 세웁니다.
7. 학력이 있어야 될 수 있는 직업이 있습니다 (의사·과학자·엔지니어·교수 = 대학교, 교사 = 고등학교…). 대학이 막 생긴 시대에는 졸업생이 없으니 나라에서 가장 많이 배운 사람이 가르칩니다 — 세대가 바뀌며 전문직이 생겨납니다.
8. 나라마다 **"최초" 연대기** 가 남습니다: 첫 불, 첫 움집, 첫 고기잡이, 첫 족장, 첫 연인, 첫 결혼식, 첫 아기, 첫 회사, 첫 건설회사, 첫 서당, 첫 학생, 첫 졸업생, 첫 홍수…

## 경우의 수

- **인생 사건 약 100가지** (`server/sim/events.js`): 첫 미소·첫 말·첫걸음, 물놀이하다 빠질 뻔한 날, 산에서 길 잃은 날, 친구와 싸우고 화해, 반장 선거, 시험, 괴롭힘, 첫사랑과 편지, 사춘기, 첫 월급, 돈주머니 줍기(성격에 따라 돌려주거나 챙기거나), 도둑, 사기, 횡재, 집들이, 취미, 등산, 바다낚시, 다침, 큰 사냥, 결혼기념일, 부부싸움, 부모님 병환, 오랜 친구와 재회, 이웃 돕기와 이웃 다툼, 불면, 중년의 위기, 기부, 손주, 유언… 나이·성격·가족·직업·지형·계절·날씨·시대에 따라 조건과 확률이 다르고, 문장 안의 사람·장소·물고기·놀이·음식이 매번 바뀝니다.
- **마을 전체의 일**: 날씨(계절·기후대별 맑음·비·폭우·눈·한파·무더위·태풍…), 홍수(강), 태풍(바다), 가뭄, 지진(산), 돌림병, 산불, 풍년 잔치, 새해, 별똥별·일식·오로라.
- **속마음 조합** (`server/sim/thoughts.js`): 감정에 따른 첫마디 × 지금 마음에 걸리는 20여 가지 주제(계절, 날씨, 산·강·바다, 배고픔, 학교, 일, 짝사랑, 가족, 돈, 꿈, 새 건물, 시대 변화, 지도자, 옛 기억, 건강, 별…)와 그 변주 × 성격에 따른 끝맺음.

## 앤은 어떻게 생각하나

`server/sim/mind.js` 의 인지 구조:

| 단계 | 내용 |
|---|---|
| 욕구 | 배부름·기력·교류·즐거움이 시간마다 줄어든다 (외향적일수록 외로움을 빨리 탄다) |
| 고민 | 잠·식사·일·구직·대화·데이트·고백·청혼·가족·연구·창작·운동·집짓기·마을 일 돕기·창업·개척… 모든 선택지에 **점수와 이유**를 붙인다 (욕구, 성격, 가치관, 꿈, 시각, 돈, 관계) |
| 선택 | 성실하지 않을수록 즉흥적이다 — 1위가 늘 이기지는 않는다 |
| 상호작용 | 대화의 질 = 성격 궁합 + 친화성 + 기분 + 매력 + 운. 친구·절친·라이벌·원수·짝사랑·연인·배우자가 생겨난다. **뒷담화** 로 다른 사람에 대한 의견이 (신뢰한 만큼) 전파된다 |
| 감정 | 신경성이 높으면 나쁜 일에 크게, 외향성이 높으면 좋은 일에 크게 반응한다 |
| 기억 | 중요도와 감정이 있는 일화 기억. 오래되고 사소한 것부터 잊는다 (중요도 8 이상은 평생) |
| 사색 | 최근 기억을 돌아보며 사람에 대한 생각을 고치고, 꿈을 다지거나 내려놓는다 |
| 밤 | 하루를 돌아보고, 맞지 않는 일은 그만두기도 한다 |
| 꿈 | 가치관(가족·부·지식·권력·예술·모험·운동·공동체·장인정신)에서 인생 목표가 생기고, 이루면 새 꿈이 생긴다 |

그 밖에: 임신(270일)과 출산, 부모를 닮은 유전(성격·능력·외모), 나이 듦과 질병, 죽음과 애도, 상속, 결혼과 이혼, 은퇴.

## 문명

- **시대**: 원시 → 농경 → 고대 → 중세 → 산업 → 근대 → 정보화 → 우주. 연구·학자·과학자가 쌓은 기술력으로 넘어가며, 시대마다 여섯 가지 발견(불, 바퀴, 문자, 인쇄술, 증기기관, 인터넷, 로켓…)을 누군가 해낸다.
- **경제**: 시대마다 직업이 바뀐다 (채집꾼·사냥꾼 → 농부·목수 → 상인·학자 → 의사·교사 → 공장 노동자·엔지니어 → 과학자·기자 → 프로그래머 → 우주비행사). 야망 있는 앤은 수요가 있는 산업에 회사를 세우고, 친분과 실력으로 직원을 뽑고, 경쟁에서 지면 파산한다.
- **정치**: 족장(추대) → 왕(세습) → 선거로 뽑는 대통령. 지도자의 성격에 따라 세율, 복지, 학당·학교·연구소를 짓는 순서가 달라진다.
- **도시**: 모닥불과 움집에서 시작해 초가집, 기와집, 벽돌집, 아파트, 초고층 빌딩으로. 건물 수와 시대에 따라 야영지 → 마을 → 읍 → 도시 → 대도시 → 메가시티. 붐비면 모험심 있는 앤이 새 땅을 개척한다.

`npm run simulate -- 730 3 KR` 로 화면 없이 2년을 빠르게 돌려 세계가 어떻게 흘러가는지 볼 수 있습니다.

## 구조

```
server/
  index.js        Express + WebSocket, 여러 서버(월드)를 동시에 1초마다 진행·전송
  geo.js          국가 다각형·한국어 이름·문화권·육지 샘플링
  store.js        월드 저장/불러오기
  sim/
    world.js      시계, 하루 단위 처리(나이·출산·죽음·병), 나라·지도자·선거·시대·발견, 직렬화
    ann.js        앤 생성·유전·기억·생각·감정
    mind.js       욕구 → 고민 → 행동 → 결과, 속마음
    social.js     관계, 대화, 뒷담화, 고백·청혼·결혼·이별
    economy.js    회사·공공기관·채용·생산·급여·세금·파산
    settlement.js 정착지, 20m 격자 위 건물 배치
    data.js       시대·발견·직업·산업·건물 표
public/
  js/scene/       three.js: 지구(셰이더·구름·대기·도시 불빛), 우주, 도시·앤 렌더링, 카메라
  js/ui/          앤 만들기, 관찰 HUD
  js/main.js      화면 흐름
```
