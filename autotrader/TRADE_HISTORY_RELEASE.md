# CORE 거래기록 복구

새 CORE의 SQLite 체결 원장을 거래기록 조회에 연결한다. 거래소 체결시각 기준으로 과거 청산도 자동 복원한다. 주문번호별로 분할 체결을 묶고, 부분 감축과 전량 청산을 구분한다. 추가 진입 후 남은 수량의 평균 단가와 배분 진입 수수료를 추적한다.

실제 수수료는 캐시된 OKX 주문번호·수량이 정확히 일치할 때 사용한다. 갱신 전에는 추정 표시하며 이후 자동 대체한다. 펀딩비는 별도이며 실제 순손익으로 오인하도록 표시하지 않는다. 기존 완전청산 통계 관례를 유지하고 부분 감축은 별도 행으로 보여준다.

조회는 읽기 전용으로 원장·주문·설정을 변경하지 않는다. 기존 손실 제한이 unified 손익을 두 번 합산하지 않도록 예전 기록만 별도로 읽는다. 마진 수익률의 기존 근접시간 매칭은 CORE에 적용하지 않고 정확한 주문 ID와 원장 진입 증거금을 사용한다.

배포: deploy_gemini.py prepare <archive> <sha256>로 검사 후 apply <prepared_release>. 기존 .env와 공유 데이터 유지.
