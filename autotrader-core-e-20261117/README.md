# Core E — ZEC 초단타 엔진 (모의 매매 전용)

날짜: 2026-11-17

**상태: 모의 매매만 가능. 실거래 승격 기준 미달(NO GO).**
CORE·Candidate C와 코드·상태·계좌를 전혀 공유하지 않는 독립 폴더다. OKX **공개** 시세만 읽고,
API 키를 받지 않으며, 주문을 내는 코드가 없다(테스트 `NoLiveOrderCodeTests`가 이를 검사한다).
설정에서 `mode`를 `paper` 말고 다른 값으로 바꾸면 시작 자체가 거부된다.

## 왜 ZEC인가

2026-11-17 OKX USDT 무기한 선물 데이터(공개 API) 기준. 봇이 이미 쓰는 코인
(BTC, ETH, XRP, PI, DOGE, SOL, ADA 확인)과 주식·금속·원유 상품은 뺐다.

| 종목 | 30일 하루 거래대금 중앙값 | 최저일 | 호가 차이 | 하루 변동폭 중앙값 | ±5bp 안 호가 물량(매수/매도) |
|---|---|---|---|---|---|
| **ZEC** | **약 12억 달러** | 5.5억 | 0.11bp(1틱) | 약 10% | 5.7만 / 5.6만 달러 |
| HYPE | 1.6억 | 0.7억 | 0.14bp | 약 5.8% | 2.1만 / 16.5만 |
| PEPE | 2.2억 | 0.7억 | 0.26bp | 약 9.9% | 4.5만 / 4.3만 |
| NEAR | 1.4억 | 0.5억 | 3.1bp | 약 8.4% | 4.4만 / 6.4만 |

ZEC는 BTC·ETH 다음으로 거래가 많고, 호가 차이가 1틱이며, 많이 움직인다.
지금 봇의 나머지 코인 3개 중에 ZEC가 있으면 다음 후보는 HYPE다.
변동이 큰 만큼 위험도 크다.

## 전략 (규칙만, AI 없음)

1. 체결을 100ms 단위로 묶는다.
2. 최근 `window_sec`(기본 20초) 동안 다음 세 가지를 동시에 만족하면 신호로 본다.
   - 가격이 `min_move_bp` 이상 움직였다.
   - 한쪽 체결이 `min_imbalance` 이상 몰렸다.
   - 거래량이 평소(최근 10분 평균)의 `min_volume_ratio`배 이상이다.
3. `style=momentum`이면 그 방향으로, `fade`이면 반대 방향으로 들어간다.
   현재가보다 `entry_offset_bp` 유리한 가격에 **지정가**를 걸고, 10초 안에 안 잡히면 취소한다.
4. 익절은 지정가(maker)로 건다. 손절과 `max_hold_sec`(3분) 시간청산은 시장가(taker)로 한다.
5. 위험 관리:
   - 하루 손실 한도(기본 15 USDT, 한국시간 0시 기준)
   - 하루 최대 거래 수
   - 연속 5번 손실 시 30분 정지
   - 청산 뒤 30초 쉬기

### 모의 체결 규칙 (일부러 불리하게)

- 지정가는 그 가격을 **건너는** 체결이 찍혀야 잡힌 걸로 친다. 같은 가격 체결은 인정하지 않는다.
- 새 주문은 150ms 뒤부터만 유효하다.
- 손절은 갭이 나면 시가로 나가고, 미끄러짐 1bp를 더한다.
- 한 묶음 안에서 손절가와 익절가가 둘 다 닿으면 손절로 처리한다.
- 수수료는 OKX 일반 등급 기준이다: 지정가 0.02%, 시장가 0.05%.

## 백테스트 결과 (ZEC 7일, 체결 약 1,600만 건)

- 학습 구간: 11/10~11/13
- 검증 구간: 11/14~11/16(OKX 하루 = UTC+8)
- 데이터는 OKX 공개 일별 체결 파일이다.

| 설정 | 구간 | 거래 | 승률 | 수수료 전 | 수수료 | 수수료 후 | PF |
|---|---|---|---|---|---|---|---|
| 기본(따라가기), 위험관리 켬 | 학습 | 262 | 40.5% | -12.00 | 44.68 | **-56.68** | 0.38 |
| 기본(따라가기), 위험관리 켬 | 검증 | 230 | 41.7% | -7.43 | 39.16 | **-46.59** | 0.40 |

- **설정 288개**를 학습 구간에서 비교했다(위험관리는 꺼서 날것의 성적을 봄).
  - 수수료 후 플러스인 설정은 **0개**였다.
  - 상위 8개를 검증 구간에 적용했더니 **8개 모두 탈락**했다.
  - 탈락 기준: 30건 이상, PF>1, 비용 3bp를 더 얹어도 플러스.
- **체결 가정을 유리하게 바꿔도 결론은 같다.** "닿기만 해도 체결 + 지연 0 + 미끄러짐 0"으로 바꿔도
  모든 설정이 수수료 후 마이너스였다.
  - 가장 나은 설정의 수수료 전 이익은 거래당 약 +1~2bp였다.
  - 수수료는 거래당 약 6bp였다.

**정리:** 이 규칙들로는 수수료(왕복 4~8bp)를 넘는 이익이 나지 않는다. 지난 v33-78 점검
(15분 주기 CORE도 비용을 빼면 PF 0.845)과 같은 방향이다. 실제 돈은 넣지 말고, 아래처럼
실시간 모의로만 더 관찰한다.

## 실행 방법

필요한 것: Python 3.11 이상, `websockets`(서버 봇 requirements에 이미 있음).

```sh
cd autotrader-core-e-20261117

# 테스트 (인터넷 불필요)
python -m unittest discover -s tests -v

# 백테스트: 날짜 파일이 없으면 OKX에서 받아온다(하루 약 15~25MB)
python -m core_e.backtest --data-dir ./data --start 2026-11-10 --end 2026-11-16 --split 2026-11-14 --download
# 설정 하나만 바꿔 보기
python -m core_e.backtest --data-dir ./data --start 2026-11-10 --end 2026-11-16 --split 2026-11-14 \
  --set style=fade --set take_profit_bp=40
# 여러 설정 비교(학습 구간에서 고르고 검증 구간에서 확인)
python -m core_e.backtest --data-dir ./data --start 2026-11-10 --end 2026-11-16 --split 2026-11-14 --grid \
  --set daily_loss_limit_usdt=100000 --set max_consecutive_losses=100000 --set max_trades_per_day=100000

# 실시간 모의 매매 (주문 없음). 처음 10분은 평소 거래량을 쌓느라 진입하지 않는다.
python -m core_e.run_paper --out /var/lib/autotrader/core_e
# 웹소켓이 막힌 곳이면 1초마다 조회하는 방식
python -m core_e.run_paper --out ./core_e_data --feed rest

# 모의 결과 보기
python -m core_e.report --ledger /var/lib/autotrader/core_e/events.jsonl
python -m core_e.report --ledger /var/lib/autotrader/core_e/events.jsonl --day 2026-11-18
```

서버에서 계속 돌릴 때는 `deploy/core-e-paper.service`(systemd 예시)를 경로만 맞춰 쓴다.

`--out` 폴더에 남는 파일:

- `events.jsonl`: 진입 주문, 체결, 취소, 청산, 끊김이 한 줄에 하나씩 쌓인다.
- `status.json`: 지금 상태다. 5초마다 바뀐다.
- `core_e.lock`: 같은 폴더로 두 개가 동시에 돌지 못하게 막는다.

재시작해도 오늘 이미 난 손실은 하루 한도에 그대로 반영된다.

## 실거래로 넘어가기 전에 필요한 것 (지금은 없음)

1. **모의 결과 확인:** 실시간 모의로 2주 이상, 300건 이상 쌓았을 때 아래를 모두 넘어야 한다.
   - 수수료 후 플러스
   - PF 1.2 이상
   - 비용을 3bp 더 얹어도 플러스
2. **계좌 분리:** OKX 서브계정을 따로 만든다. CORE·Candidate C 계좌와 섞지 않는다.
3. **실주문 모듈을 새로 만든다.** 아래가 필요하다.
   - 주문이 체결되지 않고 취소만 되게 거는 방식(post-only)
   - 진입과 동시에 거래소에 손절 붙이기
   - 거래소 포지션과 장부 대조
   - 즉시 정지 스위치

   이 폴더에는 일부러 넣지 않았다.
