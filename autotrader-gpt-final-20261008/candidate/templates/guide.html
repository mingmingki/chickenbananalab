1. Gemini API 키 발급

시세 분석/매매 판단에 쓰이는 AI 키입니다. 무료로 만들 수 있습니다.
  1. aistudio.google.com 접속 후 구글 계정으로 로그인
  2. 화면의 "Get API key" 메뉴 클릭
  3. "Create API key" 버튼 클릭 → 새 프로젝트를 만들거나 기존 프로젝트 선택
  4. 생성된 키를 복사해서 이 사이트 회원가입 후 대시보드의 "Gemini API 키" 칸에 붙여넣기
참고: 무료 등급도 이 봇 용도로는 충분하지만, 여러 종목을 자주 검토하면 비용이 조금씩 나갈 수 있습니다 (대시보드에서 실시간으로 확인 가능).

2. OKX API 키 발급

실제 주문을 넣는 데 쓰이는 거래소 키입니다. 반드시 아래 권한 설정까지 맞춰야 매매가 됩니다.
  1. okx.com 로그인 → 우측 상단 프로필 → API 관리
  2. API 생성 클릭 → API 이름 입력, 2차 인증(OTP 등)으로 본인 확인
  3. Passphrase를 직접 정해서 입력 (아무 값이나 가능하지만 꼭 기억해둘 것)
  4. 권한(Permissions)에서 반드시 "거래(Trade)"를 체크 — 읽기 전용(Read-only)이면 주문이 안 나갑니다
  5. 생성 완료 시 API Key / Secret Key / Passphrase 3개가 나옵니다. Secret Key는 이 순간만 보여지고 다시 볼 수 없으니 반드시 그 자리에서 복사해서 안전하게 보관하세요
이 단계를 빼먹으면 "거래 권한 없음(50123)" 에러가 납니다:
발급된 키 목록에서 방금 만든 키를 다시 클릭 → 상세 설정에서 마켓 타입에 "무기한 선물(Perpetual/SWAP)"을 체크하고, 매매할 코인(BTC, ETH, XRP 등)을 화이트리스트에 추가해야 합니다. 이 두 가지가 빠지면 API 키 자체는 정상이어도 실제 주문 시점에 거부됩니다.

3. GPT API 키 발급 (선택 - GPT 검증/Shadow Mode)

Gemini의 진입/청산 판단을 GPT가 한 번 더 승인/거절만 검증해서 로그로 남기는 선택 기능입니다. 비워두면 지금처럼 Gemini만으로 매매하며, 실제 주문에는 전혀 영향을 주지 않습니다.
  1. platform.openai.com 접속 후 로그인 (Gemini와 다른 별도 계정/가입 필요)
  2. 좌측 메뉴 또는 대시보드에서 "API keys" 메뉴로 이동
  3. "Create new secret key" 클릭 → 이름은 아무거나 입력하고 생성
  4. 생성된 키를 즉시 복사 (Secret Key는 이 순간만 보여지고 다시 볼 수 없습니다)
  5. 이 사이트 대시보드의 "GPT API 키 (선택)" 칸에 붙여넣고 "확인" 클릭
Gemini와 달리 무료 등급이 없습니다: OpenAI는 Billing 메뉴에서 결제 수단(카드) 등록과 최소 크레딧 충전이 필요합니다. 다만 이 봇은 Gemini가 실제 진입/청산을 판단할 때만 GPT를 검증용으로 짧게 호출하므로(hold일 때는 호출 안 함), 비용은 비교적 적게 나갑니다 — 대시보드 "API비용"에서 실시간으로 확인할 수 있습니다.

4. 회원가입 후 순서

  1. 이 사이트에서 원하는 아이디/비밀번호로 회원가입
  2. 대시보드 상단 "API 키"에 Gemini 키, OKX 키/Secret/Passphrase 입력 후 각각 "확인" 버튼으로 검증 (GPT 키는 선택사항 - 입력 안 해도 매매 시작 가능)
  3. 초록 점이 뜨면 정상 — "매매 설정"에서 레버리지/손절/익절 등을 원하는 값으로 맞춘 뒤 "시작"
주의: 이 봇은 바로 실거래로 동작합니다. 모의투자 모드가 없으니, 처음에는 레버리지를 낮게 잡고 소액으로 시작하는 걸 권장합니다.
